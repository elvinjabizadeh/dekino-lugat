# de/kino lüğət

Kino dilinin azərbaycanca lüğəti: [lugat.dekino.org](https://lugat.dekino.org)

Terminlər Google Sheets cədvəlindən oxunur ("Terminlər" və "Kanallar" vərəqləri). Cədvəl əlçatan olmayanda sayt `data.json` faylındakı ehtiyat surəti göstərir.

- `index.html`, `style.css`, `app.js`: sayt
- `data.json`: cədvəlin ehtiyat surəti
- `CNAME`: GitHub Pages üçün domen
